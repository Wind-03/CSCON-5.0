# CSCON 5.0 — Create. Build. Scale.

The OAU Creator, Business & Tech Summit — 3D Sponsorship Website

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 🏗️ Build for Production

```bash
npm run build
```

## Tech Stack

- **Next.js 15** — React framework
- **React Three Fiber** — 3D rendering
- **Three.js** — WebGL 3D engine
- **Tailwind CSS** — Utility styling

## Structure

```
app/
  page.tsx              # Main page with all sections
  layout.tsx            # Root layout
  globals.css           # Design system & global styles
  components/
    scenes/
      HeroScene.tsx     # Hero 3D particle streams
      TrackScenes.tsx   # Create/Build/Scale environments
      ReachScene.tsx    # 1M+ reach particle network
    ui/
      Navbar.tsx        # Fixed navigation
      FadeIn.tsx        # Scroll-triggered animations
```

## Sections

1. **Hero** — 3D particle streams (green/purple/cyan) with CSCON 5.0 title
2. **About** — Mission, the problem, animated stat counters
3. **Tracks** — Create / Build / Scale track breakdown
4. **Reach** — Particle network + animated counter to 1M+
5. **Speakers** — Keynote + speaker grid
6. **Schedule** — Full day timeline
7. **Packages** — Bronze / Silver / Gold / Platinum tiers
8. **Track Record** — Past editions
9. **Why Partner** — Value proposition
10. **Contact** — CTA + contact details
